# 01 - 高频面试题

## 学习目标
- 以面试题为抓手系统梳理知识
- 准备高质量的答案（不止于知道，而是能深入）
- 应对 P7+/P8 级别的架构师面试

## 整理原则
- **不要死记硬背**：每题都要能讲清楚原理
- **结构化回答**：什么是 → 为什么 → 怎么做 → 举例 → 延伸
- **关联知识**：一题带出多题
- **实战佐证**：结合项目经验

## 必答题清单（30题）

### Java核心
1. HashMap 1.7 vs 1.8 的区别？为什么要改？
2. ConcurrentHashMap 如何保证线程安全？
3. volatile 的作用与底层原理？
4. synchronized 锁升级过程？
5. AQS 的实现原理？

### JVM
6. 对象创建的完整流程？
7. G1 和 CMS 的区别？G1 的 Mixed GC？
8. 双亲委派机制？哪些场景打破了它？
9. 线上 OOM 如何排查？
10. 类加载的完整过程？

### 框架
11. Spring Bean 生命周期？
12. Spring 如何解决循环依赖？为什么是三级缓存？
13. SpringBoot 自动装配原理？
14. Spring 事务失效的场景？
15. Spring AOP 底层原理？

### 数据库
16. InnoDB 的 B+树索引？为什么是B+树？
17. MVCC 实现原理？
18. 事务隔离级别与幻读？
19. 间隙锁、临键锁？
20. 如何优化一条慢 SQL？

### Redis
21. Redis 为什么快？
22. 缓存穿透/击穿/雪崩如何解决？
23. Redis 持久化 RDB vs AOF？
24. Redis 主从/哨兵/Cluster？
25. 如何保证缓存与数据库一致性？

### 分布式/架构
26. CAP 定理？举例你系统中的权衡？
27. 分布式事务方案对比？你用过哪种？
28. 分布式锁 Redis vs ZK 对比？
29. 如何设计一个秒杀系统？
30. 如何设计一个短链系统/订单号生成？

## 答题模板
```markdown
## 问题
xxx

## 核心答案（30秒版）
一句话说清楚本质

## 详细展开（3分钟版）
### 1. 是什么
### 2. 为什么这样设计
### 3. 怎么用 / 源码原理
### 4. 有什么坑 / 最佳实践

## 延伸追问
- 可能被追问的问题1 → 答案
- 可能被追问的问题2 → 答案

## 项目实战
结合我在 xx 项目中的实际应用
```
