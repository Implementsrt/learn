# 01 - 高频面试题

## 学习目标
- 以面试题为抓手系统梳理知识
- 准备高质量的答案（不止于知道，而是能深入）
- 应对 P7+/P8 级别的架构师面试

## 整理原则
- [面试题整理规范](面试题整理规范.md)：按渐进式披露组织题库、详细知识点、题型模板和质量检查。
- **不要死记硬背**：每题都要能讲清楚原理
- **结构化回答**：什么是 → 为什么 → 怎么做 → 举例 → 延伸
- **关联知识**：一题带出多题
- **实战佐证**：结合项目经验
- **题库与知识点分工**：本目录用于快速浏览和回忆问题；完整原理、流程、边界、踩坑和排障过程进入对应知识点文档，题目缺失时再点击链接深入学习
