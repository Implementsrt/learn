## 使用指南

### 学习流程
1. **选主题**：从目录说明或感兴趣的模块挑一个
2. **读 README**：了解该模块的目标、核心内容、实战任务
3. **执行任务**：勾选 checkbox，完成实战产出
4. **写笔记**：在对应目录创建 `YYYY-MM-DD-主题.md`
5. **定期复盘**：每月回顾进度，调整节奏

### 笔记命名规范
```
YYYY-MM-DD-主题关键词.md
例如：2026-05-10-HashMap源码分析.md
```

### 笔记模板建议
```markdown
# 主题

## 背景
为什么学这个？

## 核心内容
深入展开

## 源码 / 代码示例
关键代码 + 注释

## 坑点与最佳实践
生产踩过的坑

## 延伸思考
背后的设计哲学

## 参考资料
- 书籍/博客/官方文档
```

## 学习原则

- **深度优先**：少而精，挖到底层
- **源码驱动**：带着问题读源码，不流于表面
- **实战落地**：每个知识点都要有产出
- **持续输出**：博客、分享、开源
- **保持节奏**：每周 10-15 小时，贵在坚持
