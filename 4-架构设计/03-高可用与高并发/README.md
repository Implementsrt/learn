# 03 - 高可用与高并发

## 学习目标
- 掌握高并发系统设计套路
- 理解高可用各项手段及其代价
- 能独立设计百万QPS级系统

## 高并发设计套路
### 流量处理
- **流量削峰**：MQ异步化、排队
- **限流**：网关层、应用层、数据库层
- **降级**：自动降级、手动降级
- **熔断**：快速失败、防雪崩

### 分层缓存
- **浏览器缓存** → **CDN** → **Nginx缓存** → **本地缓存（Caffeine）** → **分布式缓存（Redis）** → **数据库**
- 缓存预热、更新策略（Cache Aside / Read Through / Write Back）

### 数据层
- **读写分离**
- **分库分表**
- **冷热分离**
- **异构索引**（ES承接复杂查询）

### 异步化
- **消息队列解耦**
- **CompletableFuture 编排**
- **响应式编程**（Reactor/WebFlux）

## 高可用手段
### 冗余
- 服务多实例、多可用区、多Region
- 数据多副本
- **异地多活** vs **同城双活**

### 隔离
- **线程池隔离**（Hystrix舱壁）
- **信号量隔离**
- **机房隔离**、**机器隔离**
- **业务隔离**（核心/非核心）

### 容错
- 重试（幂等 + 指数退避）
- 超时控制（Timeout链路传递）
- Failover / Failfast / Failsafe / Failback

### 容灾
- 预案、演练（混沌工程）
- 故障自愈

## 典型场景
- **秒杀系统**：预减库存、恶意请求过滤、异步下单
- **红包雨**：令牌预发、本地扣减
- **大V推送**：推拉结合
- **弹幕系统**：无状态 + 分房间
