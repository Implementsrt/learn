# 01 - 分布式系统理论

## 学习目标
- 建立分布式系统的理论思维框架
- 理解各类算法在工程中的落地
- 能用理论指导架构设计决策

## 核心理论
### 基础理论
- **CAP定理**：一致性/可用性/分区容忍，为什么只能选2
- **BASE理论**：基本可用、软状态、最终一致
- **FLP不可能**：异步系统中无法同时保证活性与安全性
- **PACELC**：对CAP的扩展

### 一致性模型
- **强一致性（线性一致、顺序一致）**
- **弱一致性（因果一致、会话一致、单调读/写）**
- **最终一致性**

### 共识算法
- **Paxos**（Basic / Multi）
- **Raft**（Leader选举 / 日志复制 / 安全性）
- **ZAB**（ZooKeeper原子广播）
- **Gossip**（最终一致性传播）

### 分布式ID
- **UUID**：无序、太长
- **Snowflake**：41位时间+10位机器+12位序列，时钟回拨问题
- **Leaf**（美团）：号段模式 + Snowflake
- **UidGenerator**（百度）

### 限流算法
- **计数器**（固定窗口 / 滑动窗口）
- **漏桶**（流出恒定）
- **令牌桶**（允许突发）
- **Sentinel 热点参数限流**

### 分布式锁
- **Redis (Redlock)** vs **ZooKeeper** vs **etcd**
- 公平性、可重入、阻塞/非阻塞
- 锁续期（Redisson看门狗）
