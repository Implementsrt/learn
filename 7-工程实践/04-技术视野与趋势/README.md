# 04 - 技术视野与趋势

## 学习目标
- 保持对技术趋势的敏锐度
- 判断哪些值得投入、哪些是噱头
- 形成自己的技术判断力

## 关注方向（2024-2026）
### AI 与大模型
- **LLM 应用开发**：
  - RAG（检索增强生成）
  - Agent / AutoGPT
  - LangChain / LangChain4j
  - Function Calling
- **AI 辅助编程**：
  - Copilot / Cursor / Windsurf
  - CodeLlama / DeepSeek-Coder
- **向量数据库**：Milvus / Pinecone / PGVector
- **模型部署**：vLLM / Ollama

### 云原生持续演进
- **WebAssembly（Wasm）** 在云端：Spin、Wasmer
- **eBPF**：内核可观测（Cilium、Pixie）
- **Ambient Mesh**（无Sidecar的ServiceMesh）
- **Platform Engineering**（平台工程）
- **Internal Developer Platform（IDP）**：Backstage

### 数据
- **数据湖仓一体**：Iceberg、Hudi、Delta
- **实时数仓**：Flink + Doris/ClickHouse
- **流批一体**
- **DataOps / MLOps**

### 新型基础设施
- **分布式数据库**：TiDB / CockroachDB / OceanBase
- **Serverless 数据库**：Neon、PlanetScale
- **边缘计算**
- **量子计算**（长期关注）

### 编程语言趋势
- **Rust**：系统编程、WebAssembly
- **Go**：云原生首选
- **Kotlin**：JVM现代化选择
- **Java 虚拟线程、GraalVM**

### Web3（理性观察）
- 智能合约、DApp
- 去中心化存储（IPFS/Filecoin）

### 隐私计算
- 联邦学习
- TEE（可信执行环境）
- 差分隐私
