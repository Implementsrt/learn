# 03 - 缓存策略

## 学习目标
- 设计多级缓存架构
- 熟练应对缓存三大经典问题
- 理解缓存与数据库一致性方案

## 核心知识点
### 缓存分层
```
浏览器缓存 → CDN → Nginx缓存 → 本地缓存 → 分布式缓存 → 数据库
```

### 本地缓存
- **Guava Cache**：LRU、过期、回源
- **Caffeine**：W-TinyLFU（优于LRU）、异步加载
- **Ehcache**：堆内/堆外/磁盘三级

### 分布式缓存（Redis）
- 使用规范：key命名、value大小、过期时间
- **大Key治理**：识别、拆分、渐进式删除
- **热Key治理**：本地缓存、读写分离、加盐
- **Pipeline批量优化**
- **Lua原子操作**

### 缓存三大问题
- **缓存穿透**（查不存在的数据）
  - 布隆过滤器
  - 空值缓存（短TTL）
- **缓存击穿**（热点key失效）
  - 互斥锁重建
  - 永不过期 + 异步更新
- **缓存雪崩**（大量key同时失效）
  - 过期时间随机化
  - 多级缓存
  - 服务降级

### 更新策略
- **Cache Aside**（最常用）：
  - 读：先查缓存，未命中查DB回写
  - 写：先写DB，再**删除**（不是更新）缓存
- **Read/Write Through**：缓存即数据源
- **Write Back**：异步刷DB、可能丢数据
- **延迟双删**
- **Canal订阅binlog**

### 一致性分析
- 先删缓存还是先写DB？
- 删除失败如何补偿？（消息队列重试）
- 读写并发下的不一致窗口
