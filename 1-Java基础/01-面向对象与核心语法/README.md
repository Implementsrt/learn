# 01 - 面向对象与核心语法

## 学习目标
- 深入理解OOP四大特性在Java中的实现机制
- 掌握泛型、注解、异常体系的底层原理
- 能够设计出高内聚低耦合的类与接口

## 核心知识点
- **类与对象**：对象内存布局、对象头、Mark Word、压缩指针
- **继承与多态**：方法派发（静态/动态绑定）、虚方法表
- **接口**：默认方法、静态方法、函数式接口、`@FunctionalInterface`
- **泛型**：类型擦除、桥接方法、协变/逆变、`PECS`原则
- **注解**：元注解、运行时处理、编译时处理（APT）
- **异常体系**：受检/非受检、try-with-resources、异常链
- **equals/hashCode/toString/clone** 的正确实现
- **不可变对象设计**、**枚举的高级用法**

## 实战任务
- [ ] 使用 JOL 观察对象内存布局
- [ ] 实现一个支持类型安全的泛型工具类
- [ ] 编写自定义注解 + APT 处理器（编译期代码生成）
- [ ] 设计一套业务异常体系（统一错误码）

## 重要工具
- **JOL**（Java Object Layout）：对象内存分析
- **javap -c -v**：反编译查看字节码
- **Lombok** 源码：理解编译期注解处理
