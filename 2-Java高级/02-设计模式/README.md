# 02 - 设计模式

## 学习目标
- 不止背模式，而是识别问题、选择模式
- 能在 JDK/Spring 源码中看出模式的运用
- 能在架构设计中自然应用模式

## 核心知识点
### 创建型（5）
- 单例（懒汉/饿汉/双检锁/枚举/静态内部类）
- 工厂方法、抽象工厂
- 建造者、原型

### 结构型（7）
- 适配器、装饰器、代理
- 外观、桥接、组合、享元

### 行为型（11）
- 策略、模板方法、观察者
- 责任链、命令、状态
- 迭代器、中介者、备忘录、访问者、解释器

### 架构模式
- **MVC / MVP / MVVM**
- **CQRS**、**事件驱动**
- **Pipes & Filters**
- **六边形架构**、**整洁架构**

## 源码中的模式
| 模式 | 出处 |
|------|------|
| 单例 | `Runtime` |
| 装饰器 | `BufferedReader` |
| 工厂方法 | `Collection.iterator()` |
| 责任链 | Servlet Filter、Spring Interceptor |
| 模板方法 | `AbstractList`、Spring `JdbcTemplate` |
| 观察者 | Spring `ApplicationEvent` |
| 策略 | `Comparator` |
| 代理 | Spring AOP |
